## 🚀 Featured Projects

### ❄️ Smart Winter Village — IoT & AI System

**Hackathon Project · 2025**

An IoT and AI-oriented system combining real-time communication, weather and aurora forecasting, and ice detection using sensor data.

- Developed RESTful backend services using Node.js and Express.
- Implemented MQTT communication with Raspberry Pi Pico.
- Integrated weather and aurora forecast APIs.
- Designed ice detection using InfluxDB sensor data.
- Deployed backend as a Linux systemd service.

**Stack:** Node.js · Express · MQTT · InfluxDB · MicroPython · Linux
